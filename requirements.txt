# 本项目零第三方依赖，全部功能基于 Python 标准库实现。
#
# 也就是说：装好 Python 就能跑，不需要 pip install 任何东西。
#
# 语音克隆引擎（sherpa-onnx 运行时 + ZipVoice 模型 + 声码器）
# 不是 pip 包，而是软件自己下载的独立二进制，放在：
#
#   sherpa/     运行时（约 56MB）
#   models/     ZipVoice 模型 + 声码器（约 196MB）
#
# 首次使用点界面上的「一键安装」，或者运行：
#
#   python run.py setup
#
# ---------------------------------------------------------------------------

#
